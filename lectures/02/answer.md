## 宿題

- 取り組んだレベル：基礎
- 変えた設定やデータ：LoRA の rank を 16 から 64 に変更。学習データや他の設定は同じ。
- 結果：上表のとおり、r=16 は学習後の `format_rate` / `content_rate` が 100% / 90.5%、r=64 は 100% / 85.7%。最終 loss と学習時間は保存された `result.json` に記録がないため比較できない。JSON にある `seconds` は評価の所要時間であり、学習時間ではない。
- 考察：ファインチューニングは、回答の形式や決まった FAQ への応答を揃えたい場合に向いている。一方、未知の質問に対する判断や事実の正しさを保証する用途には不十分で、根拠情報の検索や確認を組み合わせる必要がある。今回の結果では rank を大きくしても内容正解率は上がらなかった。
